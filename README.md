# Alfred Zaim Workflow

Alfred から Zaim への高速記録・検索・集計・各種ツール連携を行うための高度なワークフローです。
キーボード操作のみで日常の家計管理・店舗メモ・編集・タスク化までを完結させます。

※主に手動入力メイン、メモ欄をしっかり記入している方向けです

---

### 1. 初期設定・認証（Setup & Authentication）

初回利用時、または API キーを更新する際に行う OAuth 1.0a 認証手順です。

#### 手順 1: Developer API キーの発行
Zaim Developers ( https://dev.zaim.net/ ) にてアプリケーションを登録し、Consumer ID と Consumer Secret を取得します。

#### 手順 2: 認可 URL の発行とブラウザ起動
Alfred を開き、以下のコマンドを実行します。

`auth-zaim [Consumer ID] [Consumer Secret]`

* 自動的にブラウザが起動し、Zaim の連携許可画面が開きます。
* 画面に表示された **認証コード（ランダムな英数字文字列）** をコピーします。

#### 手順 3: 認証コードの登録
Alfred を開き、以下のコマンドで認証コードを送信します。

`pin-zaim [コピーした認証コード]`

* 認証が完了し、`config.json` にアクセストークンが保存されて即座にワークフローが利用可能になります。

### 2. 新規登録（Quick & Batch Entry）

単発の爆速入力（`za`）と、買い物後のまとめて入力（`zam`）の 2 パターンに対応しています。

#### A. 単発記録（`za`）
キーボードから数打鍵で明細・行動ログを即座に登録します。

* **基本構文**: `za [金額] [メモ・店舗名]`

* **入力例**:
* `za 1200 ラーメンランチ` ➔ 1,200円の支出として登録。
* `za 0 カフェで読書` ➔ **0円登録機能**。行動ログや移動履歴として記録。
* `za 3500 居酒屋 新時代` ➔ 全角数字補正・カンマ自動除去。

* **仕様**: デフォルトで「その他支出 ＞ その他」に分類され、登録完了後に自動で詳細・編集画面が開きます。

#### B. 複数一括記録（`zam`）
レシートやテキストメモから、複数行の明細を一度にまとめて登録します。

* **基本構文**: `zam` を入力して `Enter` ➔ 拡大テキスト入力画面（Text View）が起動。

* **入力例**:
* `850 スーパー卵・牛乳`
* `1200 ドラッグストア日用品`
* `3500 ガソリン給油`

* **仕様**: 各行を自動パースして連続登録し、完了後に合計金額と成功件数が通知されます。

### 3. 履歴閲覧・検索絞り込み（Dashboard）

ショートカットキー（`Option + Command + Z`）または `zaim` コマンドで直近の明細を検索・閲覧します。

* **基本構文**: `zaim [検索キーワード] [コマンド]`
*(※ コマンドとキーワードの入力順序は自由です)*

#### 【コマンドフィルター一覧】

* **期間指定コマンド**:
* `:t` / `:today` : 今日
* `:y` / `:yesterday` : 昨日
* `:w` / `:week` : 今週（月曜日始まり）
* `:1w` / `:7d` : 直近 7 日間
* `:m` / `:month` : 今月（1日〜本日）
* `:fm` / `:fullmonth` : 今月全期間（今月末までの予定含む）
* `:lm` / `:lastmonth` : 先月（前月1日〜前月末日）
* `:ty` / `:thisyear` : 今年（1月1日〜本日）
* `:ly` / `:lastyear` : 昨年全期間

* **種別指定コマンド**:
* `:p` / `:支出` : 支出明細のみ
* `:i` / `:収入` : 収入明細のみ
* `:tr` / `:振替` : 口座間振替のみ

* **特殊コマンド**:
* `:r` / `:refresh` : **キャッシュ強制更新**（スマホ入力分などの即時同期）
* `:g` / `:genre` : カテゴリ名・ジャンル名フィールドのみを対象に絞り込み
* `:s` / `:shop` : 店舗・場所名フィールドのみを対象に絞り込み
* `:a` / `:account` : 口座名フィールドのみを対象に絞り込み
* `:memo` : メモ欄のみを対象に絞り込み

* **使用例**:
* `zaim Kyash :m` ➔ 今月の「Kyash」に関連する明細一覧
* `zaim :tr :1w` ➔ 直近7日間の口座移動履歴
* `zaim :r` ➔ ローカルキャッシュを破棄して最新データを再取得

#### 最上段リアルタイムサマリー
検索結果の最上部（1〜2行目）には、現在の絞り込み条件に応じた集計情報や今月の見込み収支がリアルタイム表示されます。最上段サマリーを選択した状態で修飾キーを押すことで、一括データ出力が発動します。

---

### 4. 修飾キーによる3系統データ出力（Export & Integration）

検索画面で最上段のサマリー行を選択し、以下の修飾キーで一括出力・連携します。

* **`Command + Enter`**: **汎用テキスト形式**
* Text View 起動。閲覧・コピーが可能で、さらに `Enter` を押すと Universal Action が起動し他のアプリへ流せます。

* **`Option + Enter`**: **Zaim形式 CSV**
* デスクトップへ自動保存。`日付,方法,カテゴリ...` の Zaim 公式インポート対応形式。Excel 分析や再取り込み用。

* **`Command + Option + Enter`**: **RTM タスク形式（参考機能）**
* Text View 起動（`Enter` で Universal Action 接続）。期限文字列を自動判定しタスク構文へ変換。

#### RTM構文パース仕様（Command + Option + Enter）※参考機能
メモ欄に「`8/18期限`」などのテキストが含まれている場合、自動的に期日フラグ `^` と指定タグに分解・整形します。
*(※ Remember The Milk 以外の各種タスク管理サービスやリマインダーアプリへの応用・連携にも活用できます)*

* **入力メモ例**: `鶏卵 西友PB 6個 8/18期限 PayPay`
* **変換後出力**: `鶏卵 西友PB 6個 ^8/18 #賞味期限 #食材`
*(※ タグ指定が不要な場合は、スクリプト上部の `RTM_DEFAULT_TAGS = ""` に変更することでタグなし出力も可能)*

### 5. 明細詳細・リアルタイム編集（Detail View & Edit）

検索結果から個別の明細を選択して `Enter` を押すと、詳細画面へ移動して各項目をインライン編集できます。

* 📝 **メモ**: `Enter` で入力ウィンドウが開き、メモを上書き変更。
* 💴 **金額**: `Enter` で入力ウィンドウが開き、金額を変更。
* 📅 **日付**: `Enter` で入力ウィンドウが開き、日付（YYYY-MM-DD）を変更。
* 📍 **場所**: `Enter` で入力ウィンドウが開き、店舗・場所名を変更（振替時は非表示）。
* 📂 **カテゴリ**: `Enter` でカテゴリ選択ピッカー（`zaim-picker`）が起動して選択（振替時は非表示）。
* 💳 **口座**: `Enter` で口座選択ピッカー（`zaim-picker`）が起動して変更。

#### カテゴリピッカーの検索仕様
* 初期状態では現在選択されているカテゴリ名が検索窓に入力されており、候補リストの最上部には現在設定中の項目が `✔` マーク付きで表示されます。
* 検索文字を消去していくことで、同じ大分類内の小分類候補から、全体カテゴリ候補へと段階的に表示対象が広がります。任意のキーワードを入力して自由に絞り込み・変更が可能です。
* **自動キャッシュクリア**: いずれかの項目を編集・保存すると、ローカルキャッシュが自動破棄され、即座に最新の情報に再描画されます。

---

### 6. メンテナンス・マスターCSV出力（Backup）

設定中の全カテゴリ・ジャンル・口座情報（非表示・隠し項目含む）を一括エクスポートします。

* **コマンド**: `zmexport`
* **出力先**: デスクトップ
* **生成ファイル**:
1. `zaim_categories_full.csv` (カテゴリ大項目一覧)
2. `zaim_genres_full.csv` (ジャンル小項目一覧)
3. `zaim_accounts_full.csv` (登録口座一覧)
* **用途**: IDマッピングの確認や、Excel等でのマスター管理・分析用。

### ■ 技術的特徴
* 外部ラッパーに依存せず、Zaim REST API を直接制御する軽量設計
* macOS 特有の Unicode (NFD/NFC) 濁点分離問題をスクリプトレベルで完全補正
* Alfred ワークフロー専用に最適化された独自ローカルキャッシュ＆即時破棄ロジック
